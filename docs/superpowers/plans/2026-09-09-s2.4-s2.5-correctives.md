# S2.4 + S2.5 Corrective Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct all audit findings in S2.4 ATS fingerprint/routing and S2.5 Greenhouse/runtime behavior without redesigning v0.3.1.3 or modifying released migration bytes v1–v14.

**Architecture:** Preserve the existing pure-adapter, host-owned-I/O, fenced-write architecture. Tighten capability honesty and provisioning identity, make Greenhouse fixtures and parsing reflect the real public Job Board API, authorize provider API hosts only through reviewed host-owned binding/provider policy, and separate absence-authority completion from the run-level child-work barrier.

**Tech Stack:** Python 3.12+, SQLite, FastAPI, pytest, existing built-in adapter/runtime pipeline.

**Spec:** `docs/spec/v0.3.1.3/02_acquisition_adapters_and_crawler.md`, `03_durable_runtime_and_persistence.md`, `04_security_and_authentication.md`, and `docs/plans/slice-2-worker-implementation-plan-v0313.md`.

## Global Constraints

- v0.3.1.3 remains authoritative; no architecture redesign.
- Released migration bytes v1–v14 remain unchanged; append a new migration only if unavoidable.
- Adapters perform no network or database I/O.
- Network authority remains host-owned and fail-closed; scraped/imported content cannot widen it.
- No run terminalization while accepted child work is open.
- Absence authority requires complete, trustworthy membership accounting.
- No S2.6+ implementation.
- Tests first for every behavior-bearing correction.
